# SuiteSparse Matrix Market Fixtures

These Matrix Market files were downloaded from the SuiteSparse Matrix
Collection on 2026-06-14. They are used as external sparse symmetric test data
for Krylov matrix-free differential tests.

The original Matrix Market comments embedded in each `.mtx` file are preserved.
Those comments identify the matrices as coming from the UF/SuiteSparse sparse
matrix collection and include matrix-specific descriptions.
